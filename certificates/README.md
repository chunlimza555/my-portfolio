# Add your certificates

1. Copy your certificate PDF, JPG or PNG files into this folder.
2. Open src/certificates.js.
3. Set the relevant `file` field to the exact filename, for example:
   `file: "azure-az900.pdf"`
4. Check the title and issuer against your certificate and correct them if needed.
5. Run npm run dev and test the View certificate link.
6. Commit the files and configuration to GitHub, then build and deploy.

File names are case-sensitive on GitHub Pages. Use simple names without spaces.
The published documents will be publicly accessible. Use copies with any private
information removed if needed.

This portfolio is a static website. Files are added through the project or GitHub;
it does not provide an online upload dashboard.
